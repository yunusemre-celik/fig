==================================================================
  FIG - Smart Desktop & Quick Action Radial Wheel (Portable)
==================================================================

Thank you for downloading Fig!
Fig is a 100% offline, lightweight, portable desktop toolkit.
No installation required. Extract anywhere and launch immediately.

------------------------------------------------------------------
QUICK START:
------------------------------------------------------------------
1. Extract ALL contents of this ZIP (Fig.exe and WebView2Loader.dll) to any folder.
   (IMPORTANT: WebView2Loader.dll must stay in the same folder as Fig.exe).
2. Double-click "Fig.exe" to launch.

------------------------------------------------------------------
WINDOWS 10 & 11 COMPATIBILITY (WEBVIEW2):
------------------------------------------------------------------
- Windows 11: Includes Microsoft Edge WebView2 Runtime by default. Fig runs out of the box.
- Windows 10: If your system lacks Microsoft Edge WebView2 Runtime,
  Fig will detect this on launch and prompt you to install it from Microsoft's official site:
  https://go.microsoft.com/fwlink/p/?LinkId=2124703

------------------------------------------------------------------
WINDOWS SMARTSCREEN NOTE:
------------------------------------------------------------------
As Fig is an independent, open-source new software release,
Windows SmartScreen may prompt you upon first launch:
  1) Click "More info".
  2) Click "Run anyway".

------------------------------------------------------------------
DEFAULT SHORTCUTS:
------------------------------------------------------------------
- Default Shortcut: Alt + Q
- Select any file(s) on your desktop or file explorer, then press Alt + Q.
- The Fig radial wheel will appear at your cursor with contextual actions
  (Image conversion, PDF tools, Resize, Crop, and more).
- Click any action segment to execute.
